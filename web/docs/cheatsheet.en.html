Processor and memory Computer Systems · usually Q8–Q15

You are given processor or memory parameters and asked to calculate performance or time. The arithmetic is easy; the hard part is reading the English wording of the question correctly.

MIPS and CPI

CPU performance

A processor works in steps called clock cycles. Each instruction takes several clock cycles.

clock frequency
how many clock cycles occur per second. 800 MHz = 800 million cycles per second, 1 GHz = 1 billion.
clock cycle time
duration of one cycle = 1 ÷ frequency. 800 MHz → 1.25 ns.
CPI
Cycles Per Instruction — the average number of clock cycles one instruction needs.
MIPS
Million Instructions Per Second — how many million instructions the processor executes per second. Higher is faster.

MIPS = clock frequency [MHz] ÷ CPI

How it is asked 2025S·Q8

A CPU has a clock frequency of 800 MHz; one instruction takes 4 clock cycles on average. What is the CPU performance in MIPS? a) 0.2 b) 20 c) 200 d) 3,200

What to give

One number: millions of instructions per second.

Solution

  1. 800 MHz = 800 million clock cycles per second.
  2. One instruction takes 4 cycles (CPI = 4).
  3. Instructions per second: 800 million ÷ 4 = 200 million.

Answer: c) 200

Instruction mix

weighted mix of instruction types

Different instruction types take different times. The question gives a table: instruction type, execution time and appearance ratio (share in the program). Without a pipeline, instructions are executed strictly one at a time.

Why MIPS = 1 ÷ time in microseconds: two "millions" meet in the formula. A μs (microsecond) is 10⁻⁶ s, a millionth of a second, and the "M" in MIPS is a million (10⁶) instructions. If one instruction takes 0.41 μs = 0.41 × 10⁻⁶ s, then in 1 s the CPU completes 1 ÷ (0.41 × 10⁻⁶) ≈ 2.44 × 10⁶ instructions — 2.44 million instructions per second, i.e. 2.44 MIPS. The 10⁶ factors cancel, so just divide 1 by the time in μs.

average time = Σ (execution time × ratio)
MIPS = 1 ÷ average time [μs] = 1,000 ÷ average time [ns]

How it is asked 2024A·Q8

Instruction mix of a CPU without a pipeline (execution time in μs × appearance ratio): register to register 0.3 × 30 %, register to memory 0.6 × 50 %, conditional branch 0.1 × 20 %. What is the approximate performance in MIPS? a) 0.03 b) 0.41 c) 2.44 d) 35.00

What to give

The MIPS value: millions of instructions per second.

Solution

  1. Average instruction time: 0.3 × 0.3 + 0.6 × 0.5 + 0.1 × 0.2 = 0.09 + 0.30 + 0.02 = 0.41 μs.
  2. Instructions per second: 1 s = 1,000,000 μs, 1,000,000 ÷ 0.41 ≈ 2,440,000.
  3. In millions: 2.44 MIPS. Option b) 0.41 is the trap: it is the average instruction time in μs, not MIPS.

Answer: c) 2.44

Performance improvement

by how many percent faster

At the same clock frequency, program processing time is proportional to CPI. The improvement is measured against the old time.

CPI = Σ (cycles × ratio)
reduction = (old − new) ÷ old

How it is asked 2024S·Q8

A 32-bit CPU runs every instruction in 1 cycle. A 16-bit CPU needs 2 cycles for 32-bit instructions (40 %) and 1 cycle for 16-bit (40 %) and 8-bit (20 %) ones. Same clock. By how many percent is processing time reduced with the 32-bit CPU? a) 28.57 b) 40 c) 50 d) 71.43

What to give

The percentage reduction in processing time.

Solution

  1. CPI of the 16-bit CPU: 0.4 × 2 + 0.4 × 1 + 0.2 × 1 = 1.4.
  2. CPI of the 32-bit CPU: 1.0.
  3. (1.4 − 1.0) ÷ 1.4 = 0.2857.

Answer: a) 28.57

Trap: 0.4 ÷ 1.0 = 40 % — you must divide by the old value.

Cache memory and hit ratio

cache and share of hits

Cache memory is a small, fast memory placed between the processor and main memory. The processor looks for data in the cache first, and only then in the slower main memory.

hit
the data is found in the cache — fast.
miss
not found, so it is read from main memory. Miss ratio = 1 − h.
hit ratio (h)
the share of accesses that hit, from 0 to 1.
effective access time
average access time as seen by the processor, weighted by hits and misses.

effective access time = h × cache time + (1 − h) × main memory time

How it is asked 2025S·Q10

System A: cache 14 ns, main memory 80 ns. System B: cache 12 ns, main memory 90 ns. At what hit ratio are their effective access times equal? a) 0.17 b) 0.20 c) 0.83 d) 1.00

What to give

The value of h.

Solution

  1. A: 14h + 80(1 − h) = 80 − 66h.
  2. B: 12h + 90(1 − h) = 90 − 78h.
  3. Set them equal: 80 − 66h = 90 − 78h → 12h = 10 → h = 0.83. Check: both give 25 ns.

Answer: c) 0.83

amount of data

one dot on the screen. 1024 × 768 = width × height in pixels.
24-bit color
24 bits per pixel = 3 bytes.
ns, μs, ms
1 s = 1,000 ms = 1,000,000 μs = 10⁹ ns.
byte / bit

The time in milliseconds.

Buffer

storage between sender and receiver

A Buffer is temporary storage. If data arrives (S per second) faster than it is taken out (R per second), S − R accumulates every second.

buffer size L ≥ (S − R) × T

Data is sent for T seconds: S per second is sent, R per second is received (S > R). What buffer size L prevents overflow? a) L < (R − S) × T b) L < (S − R) × T c) L ≥ (R − S) × T d) L ≥ (S − R) × T

Answer: d) L ≥ (S − R) × T

Pipeline

pipeline processing · related topic

An instruction is split into k stages (fetch, decode, execute…). Stages of different instructions are processed at the same time, as on an assembly line.

pipeline time = (k + n − 1) × cycle time
without pipeline = k × n × cycle time

5 stages, 10 instructions: 5 + 10 − 1 = 14 cycles instead of 50.

Availability

system availability (operating ratio)
MTBF
Mean Time Between Failures — average operating time between failures.
MTTR
Mean Time To Repair — average repair time.
availability
the share of time the system is operating (from 0 to 1).
series
series connection: works only if every component works.
parallel
parallel connection: one working component is enough.

A = MTBF ÷ (MTBF + MTTR)
series: A₁ × A₂

How it is asked 2025A·Q12

1 server (availability a), 3 clients (b each), 2 printers (c each), LAN 1. Printing works if the server, at least one client and at least one printer work. System availability? a) ab³c² b) a(1 − b³)(1 − c²) c) a(1 − b)³(1 − c)² d) a(1 − (1 − b)³)(1 − (1 − c)²)

Solution

  1. There is one server and it is always needed → factor a.
  2. All three clients fail with probability (1 − b)³ → the client group works with 1 − (1 − b)³.
  3. Printers the same way: 1 − (1 − c)².
  4. Everything is connected in series → multiply.

Answer: d) a(1 − (1 − b)³)(1 − (1 − c)²)

RAID

several disks as one — all levels

RAID (Redundant Array of Independent Disks) combines disks for speed and/or reliability. Three techniques: striping — data is split into pieces and written across several disks at once (fast); mirroring — a full copy on another disk; parity — check information from which the contents of a failed disk can be rebuilt.

ITPEC questions use RAID 0, 1, 5 and 6; levels 2, 3 and 4 appear as wrong options — recognise them by the words bit-level, byte-level, dedicated parity disk.

Hexadecimal → decimal

radix conversion

Decimal is base 10, binary is base 2, hexadecimal is base 16 (digits 0–9 and A = 10 … F = 15). Each digit is multiplied by the weight of its position: …256, 16, 1 · 1/16, 1/256…

How it is asked 2024S·Q1

What is the decimal representation of the hexadecimal number 123.4? a) 83.25 b) 83.5 c) 291.25 d) 291.5

Solution

  1. Integer part: 1 × 256 + 2 × 16 + 3 × 1 = 291.
  2. Fractional part: 4 × 1/16 = 0.25.

Answer: c) 291.25

IEEE 754 floating point

floating-point number format

A number is stored as 1.mantissa × 2^exponent. Single precision uses 32 bits:

S (sign)
sign bit, 1 bit: 0 = plus, 1 = minus.
E (exponent)
exponent, 8 bits, stored with a bias of 127.
F (fraction)
fractional part of the mantissa, 23 bits. A leading "1." is always implied before it.

value = (−1)^S × 1.F × 2^(E − 127)

How it is asked 2025A·Q1

IEEE 754 single precision bits: 0 | 10000010 | 11000…0. What decimal value do they represent? a) 0.1875 b) 0.4375 c) 6.0 d) 14.0

Solution

  1. S = 0 → the number is positive.
  2. E = 10000010₂ = 130 → 130 − 127 = 3 → 2³ = 8.
  3. 1.F = 1.11₂ = 1 + 0.5 + 0.25 = 1.75.
  4. 8 × 1.75 = 14.

Answer: d) 14.0

OS scheduling Computer Systems

The OS decides which task (process, task) runs on the CPU right now. It is asked in two ways: which state a task changes to, or compute the waiting time under a given algorithm. The second type is always solved by drawing a timeline on paper.

Task states

running, ready, waiting
running
the CPU is allocated; the task is executing.
ready
can run at once; waits only for CPU allocation.
waiting / blocked
waits for an event: I/O completion, a timer.
preemptive
the OS can take the CPU away from the running task.
priority
decides which ready task gets the CPU first.

running → (preempted) → ready
running → (waits for I/O) → waiting
waiting → (event occurs) → ready

How it is asked 2024A·Q14

A real-time OS uses preemptive priority scheduling; task A has a higher priority than task B. What does the OS do? a) A launched during B → B ready, A executed b) A launched during B → B waiting, A executed c) B launched during A → A ready, B executed d) B launched during A → A waiting, B executed

Answer: a) When A is launched during the execution of B, B is put into a ready state and A is executed. B waits for nothing but the CPU, so it is ready, not waiting.

What is computed

task timing measures
arrival time
when the task arrives.
burst time
how much CPU time it needs (CPU time, running time).
completion time
when it finishes.
turnaround time
from arrival to completion.
waiting time
time spent waiting in the ready queue.

turnaround = completion − arrival
waiting = turnaround − burst

Arrive at almost the same time → every arrival = 0, so turnaround equals the completion time.

Scheduling algorithms

who gets the CPU next
FCFSFirst-Come First-Served: in order of arrival, run to the end, non-preemptive
SJF / SPTShortest Job First / Shortest Processing Time: shortest task first. Gives the minimum average waiting time
SRTShortest Remaining Time: preemptive SJF, by remaining time
Round Robinready tasks take turns in arrival order, each gets a time slice (time quantum)
Priorityby priority; in the preemptive version a newly arrived task with higher priority takes the CPU at once. Check what counts as highest: often the smaller number

Preemptive priority

higher priority takes the CPU

How it is asked 2025S·Q14

Preemptive priority scheduling; the smallest number is the highest priority. Arrival / burst / priority: P1 0/8/2, P2 2/1/1, P3 4/2/3, P4 6/3/4. Average waiting time in ms? a) 2.75 b) 3 c) 3.25 d) 3.5

Solution

  1. 0–2: P1 (no one else has arrived).
  2. 2–3: P2 arrives with priority 1 → preempts P1.
  3. 3–9: P1 finishes its remaining 6 ms (P3 and P4 have lower priority and do not preempt).
  4. 9–11: P3, 11–14: P4.
  5. Waiting = completion − arrival − burst: P1 9 − 0 − 8 = 1; P2 0; P3 11 − 4 − 2 = 5; P4 14 − 6 − 3 = 5. Average 11 ÷ 4.

Answer: a) 2.75

Interrupts

nested interrupts by priority

Interrupt: a signal that suspends the main program (main process) so that an interrupt handler can run. Multiplex interrupts are permitted means nesting is allowed: a high-priority interrupt can interrupt the handling of a low-priority one.

How it is asked 2025A·Q8

Multiplex interrupts are permitted. Interrupt A: 0.5 ms, high priority. Interrupt B: 1.5 ms, low. B occurs at 0 and 5 ms, A at 1, 2.5 and 3.5 ms. How many ms can the main process use the CPU between 0 and 5 ms? a) 2 b) 2.5 c) 3.5 d) 5

Solution

  1. 0–1 B; 1–1.5 A (interrupts B); 1.5–2 B finishes.
  2. 2–2.5 main; 2.5–3 A; 3–3.5 main; 3.5–4 A; 4–5 main.
  3. Main: 0.5 + 0.5 + 1 = 2. Quick check: 5 − 3 × 0.5 − 1.5 = 2.

Answer: a) 2

How it is asked 2025A·Q15

Main memory holds 3 pages; pages are referenced in the order 1, 2, 3, 2, 1, 4, 5. With LRU, which page is replaced at the last reference? a) 1 b) 2 c) 3 d) 4

Solution

  1. 1, 2, 3 → memory {1, 2, 3}, now full.
  2. 2 and 1 are already in memory. 3 is the least recently used.
  3. 4 → replace 3 → {1, 2, 4}. Now 2 is the least recently used.
  4. 5 → replace 2.

Answer: b) 2

Notations and traversals Basic Theory · Algorithms

Two kinds of questions: how to write an expression without parentheses, and in what order to traverse a tree or a graph. This is pure mechanics: understand it once and these points are yours.

Infix, prefix, postfix

three ways to write an expression
infix
the usual notation: a + b.
prefix
Polish notation: the operator comes before the operands: + a b.
postfix
reverse Polish notation: the operator comes after: a b +.
operand / operator
a number or variable / an operation symbol.

1. Put parentheses around every operation in order of evaluation (× ÷ before + −, equal precedence left to right).
2. Work from the inside out: postfix = “left right operator”, prefix = “operator left right”.

How it is asked 2026S·Q5

Which is the postfix notation for a + (b × c) + (d × e)? a) a+bc×de+× b) abc×+de+× c) abc×+de×+ d) abc+×de×+

Solution

  1. Parentheses: ((a + (b × c)) + (d × e)).
  2. b × c → bc×; a + … → abc×+.
  3. d × e → de×; the outer + → abc×+ de× +.

Answer: c) abc×+de×+

Which is the prefix notation for ((a − b) / (c + d)) ^ e? a) ^e/+dc−ba b) ^−ab/+cde c) ^/−ab+cde d) ^e/−ab+cd

Solution

  1. The last operation is ^: ^ X e, where X = (a − b) / (c + d).
  2. X = / −ab +cd.

Stack: evaluating postfix

LIFO structure for evaluating expressions
stack
a pile: add on top (push), take from the top (pop). LIFO — last in, first out.
queue
a waiting line: FIFO — first in, first out.

Read from left to right.
Operand → push onto the stack.
Operator → pop the top two (the first one popped is the RIGHT operand), compute, push the result.

What is the value of the postfix expression A B 2 × + D B ÷ C × − when A = 4, B = 3, C = 5, D = 6? a) −3 b) 0 c) 3 d) 40/3

Solution (stack contents)

  1. 4, 3, 2 → × → 4, 6 → + → 10.

How to remember

  1. The name tells you where the node goes. The children are always visited left to right; the only thing that changes is when you write the node itself: pre — before its children (Node · L · R), in — between them (L · Node · R), post — after them (L · R · Node).
  2. Outline and flags. Trace a line around the tree counter-clockwise, starting to the left of the root, like the dashed line in the diagram above. The line passes each node three times: on its left, underneath and on its right. Pre-order writes the node on the left pass (first visit), in-order on the pass underneath, post-order on the right pass (last visit). The flags in the diagram mark that point.
  3. In-order: read across. If the tree is drawn neatly, in-order is simply the nodes from left to right, as if the tree were flattened into a line. For a binary search tree this is also ascending order.
  4. Everyday analogy. Pre-order is a book's table of contents: first the chapter, then its sections. Post-order is deleting a folder: first everything inside it, then the folder itself.
  5. Check an option in a second. Pre-order starts with the root, post-order ends with the root, and in in-order the root sits exactly between the left and right subtrees.

Graph traversal: DFS and BFS

visiting every vertex of a graph
vertex / edge
a point of the graph / a line connecting two vertices.
depth-first (DFS)
go deeper while there is an unvisited neighbour, then backtrack. Uses a stack.
breadth-first (BFS)
first all the neighbours, then the neighbours' neighbours. Uses a queue.
ascending order
among the neighbours, take them in alphabetical order.

How it is asked 2025S·Q6

Edges: A–B, B–C, B–D, C–F, D–E, D–F. Depth-first traversal from A, visiting vertices in ascending character order? a) ABCDEF b) ABCDFE c) ABDEFC d) ABDFEC

Solution

  1. A recursive traversal would give A B C F D E, which is not among the options. So the answer key was worked out with a stack.
  2. Stack [A]: pop A, push B.
  3. Pop B, push C and D in alphabetical order → [C, D].
  4. Pop the top one, D; push E and F → [C, E, F].
  5. Pop F (its neighbours are already marked), then E, then C.

Answer: d) A B D F E C

Trap: if the recursive order is not among the options, work it out with a stack.

OC curve

operating characteristic curve · sampling inspection

The lot is not checked item by item (100-percent inspection is expensive); a sample of n items is taken instead. If it contains no more than c defectives, the lot is accepted. The more defectives the lot has, the less often it is accepted — that is what the OC curve plots.

sampling inspection
deciding on the whole lot (N items) from a sample of n.
acceptance number c
how many defectives in the sample are still allowed (the question calls it pass quantity C).
OC curve
X — percent defective of a lot p, Y — probability of acceptance (success rate of a lot) L(p).
producer’s risk α
a good lot (few defectives, p₁) is rejected anyway: α = 1 − L(p₁). Bad for the producer.
consumer’s risk β
a bad lot (many defectives, p₂) is accepted anyway: β = L(p₂). Bad for the buyer.

L(p) = Σ (k = 0 … c) C(n, k) · pᵏ · (1 − p)ⁿ⁻ᵏ

How the curve shifts

  • larger c → looser criterion → curve moves right; the curves do not cross (2025A·Q58).
  • larger n at the same c/n ratio → curve is steeper: it separates good lots from bad ones better.
  • The ideal is 100-percent inspection: a step — accept everything up to the allowed defective ratio, nothing above it.
